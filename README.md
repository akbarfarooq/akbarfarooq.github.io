## ⚡ Architecture & Tech Stack

This project was built with a strict emphasis on performance, determinism, and high-end design principles:

- **Framework:** [Next.js 15 (App Router)](https://nextjs.org/) configured for pure static HTML export.
- **Styling:** Custom OKLCH design system built on top of [Tailwind CSS](https://tailwindcss.com/).
- **Animation:** [Framer Motion](https://www.framer.com/motion/) for performant, hardware-accelerated staggered reveals and tactile interactions.
- **Typography:** Strict 2+1 font discipline leveraging *Space Grotesk* (Display), *Inter* (Body), and *JetBrains Mono* (Code/Monospace).
- **Deployment:** Fully automated CI/CD pipeline via **GitHub Actions**, deployed directly to GitHub Pages.

## 🛠️ Local Development

To run this project locally, clone the repository and install the dependencies:

```bash
git clone https://github.com/akbarfarooq/akbarfarooq.github.io.git
cd akbarfarooq.github.io
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

## 🚢 Production Build

This project is configured to output a fully static bundle suitable for any edge network or static host:

```bash
npm run build
```
This generates the optimized static files into the `out/` directory.
